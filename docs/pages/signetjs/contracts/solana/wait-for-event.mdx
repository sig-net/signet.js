# waitForEvent

Waits for a specific event matching a given request ID. Use this after [`submitSignRequest`](/signetjs/contracts/solana/submit-sign-request), or when invoking the `sign` instruction without this class's `sign` method (e.g. for cross-contract invocations or bidirectional flows).

Every wait on the same `signer` shares one WebSocket log subscription and one polling backfill loop, so the RPC cost of many concurrent waits is that of a single one. The subscription opens with the first waiter and closes with the last. Events are matched by request id, and an event that lands before its waiter registers is served from a bounded cache of recently seen events.

## Usage

```ts twoslash
// [!include ~/snippets/code/solana/fee-delegation.ts]
const solanaChainSigContract = chainSigContract

const requestId = '0x...'
const txSignature = 'signatureOfTheSignRequestTransaction'
// ---cut---
const controller = new AbortController()

const signature = await solanaChainSigContract.waitForEvent({
  eventName: 'signatureRespondedEvent',
  requestId,
  signer: solanaChainSigContract.programId,
  afterSignature: txSignature,
  timeoutMs: 60_000,
  signal: controller.signal,
})
```

## Waiting for a Bidirectional Response

```ts twoslash
// [!include ~/snippets/code/solana/fee-delegation.ts]
const solanaChainSigContract = chainSigContract

const requestId = '0x...'
const txSignature = 'signatureOfTheSignRequestTransaction'
// ---cut---
const response = await solanaChainSigContract.waitForEvent({
  eventName: 'respondBidirectionalEvent',
  requestId,
  signer: solanaChainSigContract.programId,
  afterSignature: txSignature,
  timeoutMs: 120_000,
})
```

## Parameters

| Parameter                        | Type                                                                                | Description                                                                                           |
| -------------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `options.eventName`              | `'signatureRespondedEvent' \| 'signatureErrorEvent' \| 'respondBidirectionalEvent'` | The event to wait for                                                                                 |
| `options.requestId`              | `string`                                                                            | The request id, as returned by `getRequestId` or `submitSignRequest`                                  |
| `options.signer`                 | `PublicKey`                                                                         | The account whose log stream carries the event, normally the program                                  |
| `options.afterSignature?`        | `string`                                                                            | The backfill scans only transactions after this signature                                             |
| `options.timeoutMs?`             | `number`                                                                            | Rejects with `SignatureNotFoundError` after this long (default: 60000)                                |
| `options.backfillIntervalMs?`    | `number`                                                                            | Interval of the polling backfill (default: 30000). The tightest interval among active waiters is used |
| `options.backfillLimit?`         | `number`                                                                            | Signatures fetched per backfill scan (default: 50)                                                    |
| `options.healthCheckIntervalMs?` | `number`                                                                            | Interval of the RPC liveness probe that resubscribes when the socket looks dead (default: 10000)      |
| `options.signal?`                | `AbortSignal`                                                                       | Aborting rejects the wait with the signal's reason                                                    |

## Returns

| Event                       | Resolves with                                        |
| --------------------------- | ---------------------------------------------------- |
| `signatureRespondedEvent`   | `RSVSignature`                                       |
| `signatureErrorEvent`       | `{ requestId: string; error: string }`               |
| `respondBidirectionalEvent` | `{ serializedOutput: Buffer; signature: Signature }` |
