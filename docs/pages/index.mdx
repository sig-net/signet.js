# Sig Network Midnight Integration

> **Bringing Night Mode to other blockchains.** This integration lets a Midnight contract drive transactions on foreign chains through the Sig Network MPC, so applications keep Midnight's privacy while acting anywhere else.

This project integrates with the Midnight Network.

The [Sig Network](https://sig.network) [Distributed MPC](https://github.com/sig-net/mpc) integration for the [Midnight Blockchain](https://midnight.network) allows contracts on Midnight to execute arbitrary transactions on foreign blockchains.

> ## 🚧 Under Construction 🚧
>
> This Integration is still Under Construction.
> Use at your own risk and expect rapid iteration.

It achieves this by exposing the MPC's [sign bidirectional flow](https://github.com/sig-net/midnight-integration/tree/5e79dff78a027dbeea9ab20a76a7d6391dca8037/#sign-bidirectional-protocol-flow) to contracts on Midnight.

This repository contains the pieces that make that flow available on Midnight:
- [Client-agnostic Compact and TS SDK](/midnight/packages/midnight)
  - For Midnight Contract and dApp builders to integrate with Sig Network
  - Located in `packages/signet-midnight`
- [Sig Network Protocol Singleton Contract](/midnight/packages/midnight-contract)
  - The protocol contract that integrating Midnight contracts communicate with via cross contract call
  - Located in `packages/signet-contract`
- [Sig Network Responder Contract](/midnight/packages/midnight-responder)
  - The contract the MPC posts its responses to: its `respond` and `respondBidirectional` circuits, proven with MinoCrab-compiled circuits
  - Located in `packages/signet-responder`
- Two test caller contracts: one exercises the protocol end to end, the other is a simulator-only fixture for the chunked ledger layout
  - Located in `packages/test-caller-contract` & `packages/test-caller-contract-20-field`

Example applications built on this integration (such as an ERC20 cross chain vault demo) live in a separate repository [`sig-net/midnight-examples`](https://github.com/sig-net/midnight-examples).

Read more about the [Sign Bidirectional Protocol Flow](https://github.com/sig-net/midnight-integration/tree/5e79dff78a027dbeea9ab20a76a7d6391dca8037/#sign-bidirectional-protocol-flow), or jump straight to the [Integrator Guide](https://github.com/sig-net/midnight-integration/tree/5e79dff78a027dbeea9ab20a76a7d6391dca8037/#integrator-guide) or the [Contributor Guide](https://github.com/sig-net/midnight-integration/tree/5e79dff78a027dbeea9ab20a76a7d6391dca8037/#contributor-guide) depending on your goal. The [Prerequisites](https://github.com/sig-net/midnight-integration/tree/5e79dff78a027dbeea9ab20a76a7d6391dca8037/#prerequisites) are relevant to both.
