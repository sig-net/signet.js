# Networks and Addresses

The Signet signer, the Signet responder and the MPC root public key of each Midnight network, as `@sig-net/midnight` 0.27.0-rc.3 publishes them. Read them from the package rather than copying them:

```ts
import {
  getMpcOutputCacheUrl,
  getMpcRootPublicKey,
  getResponderContractAddress,
  getSignerContractAddress,
  MidnightNetwork,
} from '@sig-net/midnight'

const signerContractAddress = getSignerContractAddress(MidnightNetwork.Preview)
const responderContractAddress = getResponderContractAddress(
  MidnightNetwork.Preview
)
const mpcRootPublicKey = getMpcRootPublicKey(MidnightNetwork.Preview)
const mpcOutputCacheUrl = getMpcOutputCacheUrl(MidnightNetwork.Preview)
```

Each getter throws for a network with no published value yet.

## Local stack

A local stack has no fixed values: its setup deploys a fresh signer and responder and generates a fresh MPC root key. See the [Contributor Guide](/midnight/contributor-guide).
